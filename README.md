# VTU Digital Library Management System

A PHP and MySQL based web application for managing a digital library for VTU students, teachers, and administrators.

## Features

### Student
- Student registration and login
- Browse and search books
- View available copies and e-book links
- Issue books
- Preorder books
- View issued books
- Renew issued books
- View profile

### Teacher
- Teacher registration and login
- Search and view books
- View teacher profile

### Admin
- Admin login
- Add, edit, and delete books
- View students and teachers
- View issued books
- Manage preorders
- Process book returns

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP

## Local Setup

1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Create a MySQL database named `vtulibrary`.
4. Configure `php/db.php` with your local MySQL settings.
5. Open `http://localhost/vtulibrary/` in a browser.

> This repository contains application source code. A database dump is not included.
